# Rysowanka

Rysowanie dla najmłodszych. Ołówek, kredka, flamaster, pędzel, zakreślacz, świecący pisak, tęczowy pisak, spray, brokat, wiaderko z farbą i gumka. Do tego 16 kolorów, 5 grubości, kolorowe kartki i około 280 naklejek (zwierzęta, morze, przyroda, jedzenie, pojazdy, serduszka, buźki, bajki). Gra nie wymaga czytania, bo lektor mówi nazwy narzędzi i kolorów.

Zagraj: https://jacekmoss.github.io/rysowanka/

Rysunki zapisują się w galerii na urządzeniu (IndexedDB). Nic nie ginie: „Nowa kartka” i otwarcie innego rysunku same chowają bieżący rysunek do galerii. Z galerii można zapisać obrazek jako PNG (na telefonie przez „Udostępnij”).

Działa bez internetu po pierwszym otwarciu (service worker `sw.js`). Na telefonie lub tablecie wybierz w Chrome „Zainstaluj aplikację” albo „Dodaj do ekranu głównego”.
